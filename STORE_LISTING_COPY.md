**Description**  
Rebar Planner helps contractors, estimators, builders, and rebar fabricators organize foundation reinforcement from project dimensions to a shop-ready material package.

Enter foundation dimensions manually or use supported plan-extraction tools, review calculated rebar requirements, and create clear schedules for cutting, bending, purchasing, and field installation.

PLANNING TOOLS
• Enter wall, footing, pier, spacing, lap, cover, and bar-size information
• Calculate horizontal, vertical, base, pier, and miscellaneous reinforcement
• Organize identical shapes and quantities
• Review missing values and calculation warnings before finalizing

CUTTING AND MATERIALS
• Create consolidated rebar cut lists
• Plan cuts from standard stock lengths
• Reuse suitable remaining pieces and reduce waste
• Track stick assignments, cuts, bends, and material quantities
• Estimate material, cutting, and bending costs

PROJECT OUTPUT
• Save and reload projects
• Generate schedules and material takeoffs
• Export organized shop information
• Create visual shape references for fabrication and field use

Rebar Planner is a planning and estimating aid. Final reinforcement design and code compliance must be reviewed by the project’s qualified design professional.
